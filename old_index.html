Choose by the result you need

For advertising, start with a row marked Ads: Yes. A security resolver such as Quad9 or Cloudflare Security focuses on malicious domains. Family filtering adds restrictions on content; it is not automatically an ad blocker.

Understand list variants

Control D hosts several community blocklists. Their maintainers and the DNS operator are different parties. HaGeZi TIF targets threats; the Light → Ultimate variants include ad filtering. More aggressive filtering can interrupt useful app features. Maintainer's comparison.

Set it up in under a minute

On Android 9 or later, search Settings for “Private DNS”.

01

Choose a profile

Compare its filtering categories. Copy the bare hostname from a card or table row.

02

Open Private DNS

Settings → Network & internet. Samsung may place it under Connections → More connection settings.

03

Paste & save

Select “Private DNS provider hostname”. Paste exactly one value and select Save.

04

Verify on your phone

Use the tools below on Wi-Fi and mobile data. Check normal browsing as well as filtering.

AdGuard Android steps · Google network settings.

Hostname, URL or blocklist?

dns.adguard-dns.com fits Android Private DNS. A DNS-over-HTTPS URL belongs in a compatible browser or app. A hosts file or downloadable blocklist requires filtering software; it cannot be pasted into this Android field.

DNS has a specific reach

DNS filtering blocks domain lookups. It cannot reliably remove ads served from the same domains as the content, including many YouTube ads. It also does not hide your IP address or prevent browser fingerprinting. DNS filtering limitations.

Test the right thing

Provider diagnostics, independent checks and a research tool — each measures something different.

Official · provider diagnostics

AdGuard diagnostics ↗

Inspect AdGuard DNS, app and extension status separately. A DNS connection does not mean the AdGuard browser extension is installed, and this is not a universal blocking score.

Independent · open source

d3ward Ad Block Test ↗

Checks a sample of advertising and tracking requests. Results reflect your browser, extensions, DNS and network together. A percentage applies to this sample, not the whole internet.

Nonprofit · privacy research

EFF Cover Your Tracks ↗

Tests tracking protection and browser fingerprinting. DNS filtering alone cannot fix a distinctive fingerprint. The test contributes data to EFF's research; see its methodology.

Official · NextDNS

NextDNS connection status ↗

Inspect the connection's reported status and protocol when using NextDNS. It does not benchmark how many ads are blocked.

Official · Cloudflare

Cloudflare connection check ↗

Checks whether Cloudflare DNS is in use and reports protocol details. “No” can be expected when you intentionally use another provider. Documentation.

Official · Mullvad

Mullvad connection check ↗

Inspect DNS resolvers and WebRTC results. Its VPN verdict is specific to Mullvad; a different intended DNS provider is not automatically a leak.

Independent · resolver discovery

DNSLeakTest ↗

Use Standard or Extended to see which resolvers answer browser-triggered lookups. Compare their operator with your intended setup.

Independent · browser diagnostics

BrowserLeaks DNS ↗

Provides another view of the resolvers visible from your browser. Hosting-network names may differ from the DNS service's brand.

Official · domain lookup

Control D filter checker ↗

Check a domain against a selected public filter. This queries the provider's policy; it does not prove your Android phone is using that resolver.

When something does not work

Android cannot connect to the Private DNS server

Check the spelling, complete any Wi-Fi sign-in page, and try another network. A network may block TCP 853, or the resolver may be unavailable. Return to Private DNS → Automatic to restore the network's DNS, then try a different documented hostname.

A site or app stopped working after enabling filtering

Try a less restrictive profile from the same provider. Public presets normally do not offer your own exceptions; use a personal profile if you need an allowlist. Do not infer that a failed site is malicious solely because a blocklist contains it.

Can I combine several hostnames or blocklists?

Android accepts one provider hostname. Multiple profiles from the same operator are alternative configurations, not values to concatenate. Use a provider's configurable profile to combine lists. A bare blocklist URL is not a DNS resolver.

Do VPNs or browser Secure DNS change the result?

They can. The interaction depends on Android version and the VPN or browser. A browser using its own DNS-over-HTTPS provider can bypass your intended system resolver. Inspect the active resolver under the exact configuration you plan to use.

Does a good leak test prove my entire phone uses DoT?

No. A browser test observes lookups triggered by that browser. Other apps may use their own DNS. It also does not prove all ads are blocked or measure all network traffic.

Why are some non-ad-blocking addresses included?

They are useful for threat-only protection, family filtering, comparison or troubleshooting. Select “Ad blocking” to retain only profiles advertising that category. Google Public DNS, standard Cloudflare and the public Quad9 profiles are not general ad blockers.
